# 神经网络第一次作业

本作业旨在通过不同的策略（包括不同的学习率和数据增强技术）来训练和评估几种深度神经网络用于图像识别的结果，实验使用ResNet152模型。

## 目录

### EX1：
- `resnet152_flower.py`：配置文件，用于配置代码运行的各种参数，包括模型指定，数据集加载，以及学习策略。
- `merge.py`：用于拆分数据集。
- `build_dict.py`：生成字典。
- `build_dataset.py`：生成训练集和验证集。
- `build_txt.py`：生成类文件和训练，验证文档。
- `flower_dataset`：拆分为训练集和测试集的数据集。
- `best_modelforEX1.pth`：最终运行的模型文件，识别准确率约为92%。

### EX2：
- `ECE371_Neural_Networks_and_Deep_Learning_Template__Copy_.pdf`：实验报告。
- `best_modelforEX2.pth`：保存的最优模型,准确率约为80%。
- `main.py`：修改后的main函数。
